# SEO Audit — Eagle Cabinetry

## Site: eaglecabinetry.pro
## Source: Ubersuggest Site Audit
## Date: 2026-03-14

---

## Issues Found

### 1. THIN CONTENT — HIGH SEO Impact
Pages with word count below Google's recommended minimum (~300+ words). Pages under 200 words are essentially invisible for organic ranking.

| Page | Word Count | Priority |
|------|-----------|----------|
| /gallery/ | 59 words | Fix now |
| /showroom-tour/ | 61 words | Fix now |
| /contact/ | 77 words | Fix now |
| /2023/11/25/hello-world/ | 142 words | Fix or delete |
| /testimonial/brittney-phillips/ | 139 words | Expand |
| /testimonial/amelia-banks/ | 155 words | Expand |
| /testimonial/lorena-jonas/ | 170 words | Expand |

**Solution:** Add substantive copy to each page. Gallery/showroom pages should include at minimum: intro text, what to expect, CTA. Testimonial pages should have a short case description + outcome.

---

### 2. MISSING META DESCRIPTIONS — MEDIUM SEO Impact

| Page | Meta Description |
|------|-----------------|
| /gallery/ | None (0 chars) |
| /showroom-tour/ | None (0 chars) |

**Solution:** Write a 140–160 character meta description for each page with the primary keyword and a CTA.

---

### 3. TITLE TAGS TOO SHORT — MEDIUM SEO Impact
Current titles are generic and missing keywords. Google needs keywords in the title to understand what each page ranks for.

| Page | Current Title | Problem |
|------|--------------|---------|
| / | Home - Eagle Cabinetry | No keyword |
| /about/ | ABOUT - Eagle Cabinetry | No keyword, all caps |
| /contact/ | CONTACT - Eagle Cabinetry | No keyword |
| /gallery/ | GALLERY - Eagle Cabinetry | No keyword |
| /services/ | SERVICES - Eagle Cabinetry | No keyword |

**Recommended Titles:**
| Page | Recommended Title |
|------|------------------|
| / | Kitchen Cabinets Birmingham AL \| Eagle Cabinetry |
| /about/ | About Eagle Cabinetry \| Custom Cabinets Birmingham AL |
| /contact/ | Contact Eagle Cabinetry \| Free Cabinet Consultation |
| /gallery/ | Cabinet Project Gallery \| Eagle Cabinetry Birmingham AL |
| /services/ | Custom Kitchen & Bathroom Cabinets \| Eagle Cabinetry |

---

### 4. NON-SEO-FRIENDLY URL — MEDIUM SEO Impact

| URL | Issue |
|-----|-------|
| /testimonial/ | Flagged as non-friendly |

**Solution:** Consider renaming to /testimonials/ or /reviews/ and ensure it contains relevant keyword context.

---

## Priority Fix Order

1. **Title tags** — fastest fix, highest impact (30 min to fix all 5)
2. **Meta descriptions** on gallery and showroom-tour
3. **Thin content** on gallery and showroom-tour (these are important pages)
4. **Thin content** on contact page (add a brief service area description + map context)
5. **Hello World** post — either delete or repurpose as a real article
6. **Testimonial pages** — expand each with 150+ more words of context

---

## Overall Assessment

The site has the right structure (local pages, services, gallery) but is essentially invisible to Google because:
- No keywords in title tags
- No meta descriptions on key pages
- Most pages have too little content for Google to rank

These are all fixable issues. None require technical work — they are content and settings fixes.
