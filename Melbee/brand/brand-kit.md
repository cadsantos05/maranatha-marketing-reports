# Melbee — Brand Kit

## Logo
- Primary: "mel✳bee" lowercase with asterisk/star icon as the bee
- Color versions: orange (#D37B30) and gray
- Alternative logos: circular badge version, horizontal text versions
- Style: modern, warm, friendly, lowercase

## Color Palette
| Name | Hex | Use |
|------|-----|-----|
| Brand Orange | `#D37B30` | Primary — logo, CTAs, headings |
| Lavender | `#C8A0CD` | Accent — highlights, tags |
| Deep Purple | `#5B0A4C` | Dark accent — contrast, backgrounds |
| Terracotta | `#B06948` | Secondary warm — cards, borders |
| Cream | `#F6F0E6` | Background — page backgrounds, cards |
| Light Mint | `#F1F6EE` | Secondary background |

## Typography
| Font | Use |
|------|-----|
| **Inter** | Primary — body text, UI, paragraphs |
| **Raleway** | Secondary — headings, display text |

## Brand Feel
Warm, approachable, professional. Earthy tones (orange, terracotta, cream) balanced with feminine accents (lavender, purple). Modern minimalist with personality.

## Moodboard Themes
- Dried citrus / organic textures
- Coffee / lifestyle
- Warm neutrals
- Lavender florals
- Clean editorial layouts

## Voice / Positioning
"Marketing driven by strategy, not guesswork."
Structured, clear, systems-oriented. Not salesy — confident and educational.
